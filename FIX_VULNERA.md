## FASE 3 — Overrides de pnpm para transitivos

Los overrides actuales en `package.json` (de UPGRADE-MINIMAL):
```json
"pnpm": {
  "overrides": {
    "shell-quote": ">=1.8.4",
    "cross-spawn": ">=6.0.6"
  }
}
```
**NO borrar los existentes.** Añadir los nuevos junto a ellos.

- [ ] 3.1 **tar (CRITICAL):** la advisory `node-tar` afecta a `<=7.5.18`.
  En el lockfile hay `tar@6.2.1` y `tar@7.5.9`, ambas vulnerables.
  Probar override global:
  ```json
  "tar": ">=7.5.19"
  ```
  Luego:
  ```bash
  pnpm install
  pnpm run dist:linux   # node-gyp/electron-rebuild deben seguir funcionando
  ```
  - Si el build rompe (algún consumer exige API de tar@6), cambiar a
    override con scope para arreglar solo la línea v7 y aceptar tar@6
    como residual dev-only:
    ```json
    "tar@>=7.0.0 <=7.5.18": ">=7.5.19"
    ```
- [ ] 3.2 **uuid@8.3.2 (deprecated):** override a ^9 (dual CJS/ESM,
  compatible con consumers CJS antiguos como la cadena react-devtools):
  ```json
  "uuid": "^9.0.0"
  ```
  ```bash
  pnpm install && pnpm run test
  ```
  Si falla, probar `"uuid": "^8.3.2 || ^9.0.0"` o revertir solo esta entrada.
- [ ] 3.3 **glob / rimraf / inflight (deprecated, vulns en glob viejo):**
  identificar consumers antes de tocar nada:
  ```bash
  grep -B30 "glob@7.2.3" pnpm-lock.yaml | head -40
  grep -B30 "glob@10.5.0" pnpm-lock.yaml | head -40
  grep -B30 "rimraf@" pnpm-lock.yaml | head -40
  ```
  - `glob@10.5.0` → intentar `"glob@^10": "^11"` (v11 es API-compatible
    con v10 en la mayoría de usos: cacache/foreground-child).
  - `glob@7.2.3` → sus consumers (rimraf@3, test-exclude, etc.) piden
    `^7` estrictamente; NO forzar a v11 (rompe API). **Aceptar como
    residual dev-only** salvo que el consumer pueda actualizarse.
  - `rimraf@2/3` → NO forzar a v4+ globalmente (cambio de API).
    **Aceptar como residual dev-only.**
  - `inflight` → viene de glob@7; se acepta mientras glob@7 se acepte.
- [ ] 3.4 Verificación de la fase completa:
  ```bash
  pnpm install
  pnpm run codecheck
  pnpm run test          # mismos 4 fallos preexistentes
  pnpm run dist:linux    # debe compilar
  pnpm audit | tail -3   # la critical de tar debe desaparecer
  ```
- [ ] 3.5 Commit: `chore: add pnpm overrides for tar, uuid (and glob if safe)`
